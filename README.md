# Complain Portal

A modern **Complain Portal** that allows users to submit complaints, track their status, and manage them efficiently. Built for seamless user experience and ease of management.

## Features

- 📝 **Submit Complaints:** Users can easily submit their complaints via a simple form.
- 📊 **Track Status:** Users can check the status of their complaints in real-time.
- 🔒 **Authentication:** Secure login and registration system for users and admins.
- ⚡ **Responsive Design:** Works perfectly on mobile, tablet, and desktop.
- 🛠️ **Admin Dashboard:** Admins can view, manage, and update complaints quickly.
